Kiedy klient zapłaci fakturę? When will the customer pay?

Zbiór zawiera 50 000 faktur, z których 42,4% zostało opłaconych po terminie. Celem projektu jest oszacowanie terminu płatności nieopłaconych faktur oraz wskazanie klientów wymagających kontaktu w pierwszej kolejności.

The set has 50,000 invoices, of which 42.4% were paid late. The project estimates when unpaid invoices will be paid and shows which customers to contact first.

Najpierw poprawiam daty zapisane w formacie liczbowym (20190307), a następnie obliczam czas płatności i liczbę dni opóźnienia. Prognoza wykorzystuje historię danego klienta. Jeżeli jest ona niedostępna, model korzysta z danych dla podobnych warunków płatności lub całego zbioru. Na wydzielonym zbiorze późniejszych faktur średni błąd wyniósł 3,39 dnia. Dla prostego modelu bazowego było to 5,48 dnia.

First I fix dates stored as numbers (20190307), then compute time to pay and days late. The forecast uses that customer’s history. If none is available, it uses similar payment terms or the whole set. On later invoices held out for testing, mean error was 3.39 days. A simple baseline was 5.48 days.

SQL — customer contact priorities

-- Wskaźnik priorytetu: przewidywana liczba dni × wartość faktury.
WITH closed AS (
  SELECT customer_id,
         AVG(julianday(clear_date) - julianday(posting_date)) AS med_days
  FROM fact_invoice
  WHERE is_open = 0
  GROUP BY customer_id
)
SELECT i.invoice_id, i.customer_id, i.amount,
       ROUND(COALESCE(c.med_days, 15), 1) AS predicted_days,
       ROUND(COALESCE(c.med_days, 15) * i.amount, 0) AS call_priority
FROM fact_invoice i
LEFT JOIN closed c USING (customer_id)
WHERE i.is_open = 1
ORDER BY call_priority DESC
LIMIT 20;
