Od ceny ropy do ceny benzyny From crude price to petrol price

Projekt automatycznie pobiera i łączy dane z EIA, NBP oraz Komisji Europejskiej. Następnie ujednolica waluty i jednostki, sprawdza poprawność danych oraz zapisuje wyniki w bazie SQLite. Narzędzia: Python, requests, pandas, SQLite, pytest.

The project automatically fetches and joins data from EIA, NBP and the European Commission. It then unifies currencies and units, checks the data and writes the results to SQLite. Tools: Python, requests, pandas, SQLite, pytest.

Pobieranie danych z APIFetching data from the APIs

3 / 8

Pobieram trzy źródła osobno. Każde wywołanie ma limit czasu i sprawdzenie statusu HTTP. Błędy połączenia są zapisywane w logach i nie prowadzą do utworzenia niepełnego wyniku.

I fetch three sources separately. Each call has a time limit and an HTTP status check. Connection errors are written to the logs and do not produce a partial result.

  • EIA — trzy poziomy: API v2 z kluczem, publiczne arkusze bez klucza (miesięczne RBRTEm/RWTCm i dzienne RBRTEd/RWTCd), a na końcu wartości referencyjne. Poziom, który zadziałał, trafia do kolumny crude_source. Projekt można odtworzyć bez prywatnego klucza API — arkusz dzienny kończy się na poprzedniej sesji.
  • NBP: GET api.nbp.pl/api/exchangerates/rates/a/{usd,eur}/{start}/{end}/ — okna po 366 dni, bo API ogranicza zapytanie.
  • KE: pobranie XLSX Weekly Oil Bulletin (ceny z podatkiem i bez, Polska).
  • Limit czasu wynosi 30 sekund — żądanie nie wisi w nieskończoność.
  • raise_for_status() — kod 4xx/5xx jest błędem, nie pustą tabelą.
  • 404 z NBP to nie awaria — oznacza okno bez dni publikacji (święta), więc zwracam pustą listę.
  • Ponowienia: 2 próby przed zgłoszeniem błędu; log mówi, które źródło i które okno padło.
  • EIA — three tiers: API v2 with a key, public keyless workbooks (monthly RBRTEm/RWTCm and daily RBRTEd/RWTCd), then reference values as a last resort. Whichever tier answered is written to the crude_source column. No key is needed for the monthly or the daily series — the daily workbook is in fact the fresher of the two, since it closes on the previous session.
  • NBP: GET api.nbp.pl/api/exchangerates/rates/a/{usd,eur}/{start}/{end}/ — 366-day windows, since the API caps each query.
  • EC: download Weekly Oil Bulletin XLSX (prices with and without tax, Poland).
  • The time limit is 30 seconds — the request does not hang forever.
  • raise_for_status() — 4xx/5xx is an error, not an empty table.
  • A 404 from NBP is not a failure — it means a window with no publication days (holidays), so I return an empty list.
  • Retries: 2 attempts before raising; the log names the source and the window that failed.
for attempt in range(retries + 1):
    try:
        response = requests.get(url, timeout=30)
        if response.status_code == 404:      # window with no publication days
            return {"rates": []}
        response.raise_for_status()
        return response.json()
    except requests.RequestException as exc:
        logger.warning("NBP failed (%s %s..%s, attempt %d): %s",
                       currency, start, end, attempt + 1, exc)
raise RuntimeError(f"NBP API unavailable for {currency}")

Przetwarzanie i łączenie źródełProcessing and merge

4 / 8

Serie miesięczne łączę po dacie. Z trzech JSON/XLSX powstaje jedna tabela: ropa, kursy, cena na stacji i różnica cen. Obie strony porównania muszą być w tej samej walucie i tej samej jednostce objętości.

Monthly series are joined on date. Three JSON/XLSX sources become one table: crude, FX, pump price and the retail–crude gap. The key constraint: both sides of that comparison must share one currency and one volume unit.

  • JSON / XLSX → pandas DataFrame.
  • Join po miesiącu: Brent + USD/PLN + EUR/PLN + Pb95/diesel.
  • Brent USD/bbl × USD/PLN = Brent PLN/bbl.
  • Brent PLN/bbl ÷ 158,987 l = Brent PLN/l.
  • Pb95 EUR/l × EUR/PLN = Pb95 PLN/l — bez tego kroku różnica cen mieszałaby dwie waluty.
  • Różnica = Pb95 PLN/l − Brent PLN/l. To nie tylko podatki i marża: w pozostałej części ceny są też rafinacja, transport i dystrybucja.
  • Liczone są też zmiany z miesiąca na miesiąc oraz względem tego samego miesiąca rok wcześniej. Dla Pb95 na cenie w PLN/l, dla Brent na notowaniu w USD.
  • JSON / XLSX → pandas DataFrame.
  • Join on month: Brent + USD/PLN + EUR/PLN + Pb95/diesel.
  • Brent USD/bbl × USD/PLN = Brent PLN/bbl.
  • Brent PLN/bbl ÷ 158.987 l = Brent PLN/l.
  • Pb95 EUR/l × EUR/PLN = Pb95 PLN/l — without this step the comparison would mix two currencies.
  • Gap = Pb95 PLN/l − Brent PLN/l. That remainder is not only tax and margin: it also includes refining, transport and distribution.
  • Month-on-month and year-on-year changes are also computed. For Pb95 on the PLN/l price, for Brent on the USD quote.
df["brent_pln_bbl"] = df["brent_usd"] * df["usd_pln"]
df["brent_pln_l"]   = df["brent_pln_bbl"] / LITRE_PER_BBL

Dane są zapisywane dopiero po poprawnym zakończeniu walidacji. validate() blokuje zapis, a pytest sprawdza gotowy CSV osobno. Testy pilnują jednostek i zakresów, nie tylko obecności kolumn.

The data are written only after validation finishes correctly. validate() blocks the write, and pytest checks the finished CSV separately. The tests watch units and ranges, not just whether columns exist.

  • Daty są unikalne, jeden wiersz na miesiąc, bez dziur w szeregu.
  • USD/PLN mieści się w 3,0–5,2, EUR/PLN w 3,5–5,5, implikowany EUR/USD w 0,9–1,35.
  • brent_pln_l musi wynikać z podziału przez 158,987. pb95_pln_l musi być przeliczony kursem EUR, nie USD.
  • test_spread_is_same_currency_subtraction pilnuje, żeby różnica cen nie odejmowała PLN/l od EUR/l.
  • Różnica brutto musi być dodatnia i mieścić się w 1,5–6 PLN/l. Różnica netto musi być mniejsza od brutto.
  • Jeśli ropa ma mało unikalnych wartości, znacznik źródła musi to przyznawać.
  • Dates are unique, one row per month, no gaps in the series.
  • USD/PLN stays in 3.0–5.2, EUR/PLN in 3.5–5.5, implied EUR/USD in 0.9–1.35.
  • brent_pln_l must follow from dividing by 158.987. pb95_pln_l must use the EUR rate, not the USD one.
  • test_spread_is_same_currency_subtraction checks that the retail–crude gap does not subtract PLN/l from EUR/l. That bug happened once.
  • The gross gap must be positive and inside 1.5–6 PLN/l. The net figure must be smaller than the gross one.
  • If crude has few distinct values, the source flag has to say so.

def test_spread_is_same_currency_subtraction(df):
    """Regression guard: the gross spread once subtracted PLN/l from EUR/l."""
    both = df.dropna(subset=["pb95_pln_l", "brent_pln_l", "spread_retail_vs_crude"])
    expected = both["pb95_pln_l"] - both["brent_pln_l"]
    assert (both["spread_retail_vs_crude"] - expected).abs().max() < 1e-9

def test_gross_spread_positive(df):
    """Excise plus VAT alone put the pump price well above bare crude cost."""
    assert df["spread_retail_vs_crude"].dropna().gt(0).all()

Po przetworzeniu dane są zapisywane w bazie SQLite i w CSV. Zapis jest idempotentny: INSERT … ON CONFLICT(date) DO UPDATE aktualizuje istniejący miesiąc zamiast go duplikować, więc skrypt można uruchamiać cyklicznie bez psucia tabeli.

After processing, the data are written to SQLite and CSV. The write is idempotent: INSERT … ON CONFLICT(date) DO UPDATE updates an existing month instead of duplicating it, so the script can run on a schedule without corrupting the table.

  • CSV: data/processed/energy_market.csv — 103 miesiące (2018–2026).
  • SQLite: data/database/energy.db — tabela energy_market, 21 kolumn.
  • Klucz główny: date — jeden wiersz = jeden miesiąc.
  • Świadomie nie używam to_sql(if_exists="replace") — to skasowałoby klucz główny i indeks ze schema.sql.
  • Zapis porównuje kolumny z PRAGMA table_info i przerywa, jeśli schemat rozjechał się z danymi.
  • CSV: data/processed/energy_market.csv — 103 months (2018–2026).
  • SQLite: data/database/energy.db — energy_market table, 21 columns.
  • Primary key: date — one row = one month.
  • Deliberately not to_sql(if_exists="replace") — that would drop the primary key and index defined in schema.sql.
  • The write compares columns against PRAGMA table_info and aborts if the schema drifted from the data.

SQL — pytania do danych po przetworzeniuSQL — questions on the processed data

Po przetworzeniu dane są zapisywane w bazie SQLite (energy_market). Poniższe zapytania odczytują ten zbiór. Pełny plik: sql/queries.sql.

After processing, the data is stored in SQLite (energy_market). The queries below read that set. Full file: sql/queries.sql.

1. Ile z ceny Pb95 to ropa, a ile pozostała część — i jak to się zmienia?

1. How much of the pump price is crude, and how much is the rest — over time?

SELECT date,
       ROUND(brent_pln_l, 2)            AS crude_pln_l,
       ROUND(pb95_pln_l, 2)             AS pump_pln_l,
       ROUND(spread_retail_vs_crude, 2) AS retail_minus_crude,
       ROUND(100.0 * brent_pln_l / pb95_pln_l, 1) AS crude_share_pct
FROM energy_market
WHERE pb95_pln_l IS NOT NULL
ORDER BY date;

Wynik: różnica 2,72–5,11 PLN/l (średnio 3,86). W lipcu 2026 ropa to ok. 28% ceny na stacji — pozostała część obejmuje między innymi podatki, rafinację, transport, dystrybucję i marże.

Result: the gap is 2.72–5.11 PLN/l (mean 3.86). In July 2026 crude is about 28% of the pump price — the remainder includes taxes, refining, transport, distribution and margins.

2. Przygotowanie szeregu miesięcznego do analizy korelacji

2. Preparing the monthly series for the correlation check

SELECT date, brent_usd, pb95_pln_l
FROM energy_market
WHERE brent_usd IS NOT NULL AND pb95_pln_l IS NOT NULL
ORDER BY date;

To zapytanie nie liczy korelacji ani nie porównuje przesunięć — tylko porządkuje szereg miesięczny. Korelacje dla poszczególnych przesunięć policzyłem w Pythonie. Najwyższa wartość jest bez przesunięcia (ok. 0,77). To wskazuje na współzmienność, ale nie dowodzi związku przyczynowego ani tego, że stacje reagują w tym samym miesiącu.

This query does not compute a correlation or compare shifts — it only orders the monthly series. Correlations at each shift were computed in Python. The highest value is at no shift (about 0.77). That shows they move together; it does not prove causation or that stations react in the same month.

3. Co ukrywa średnia miesięczna?

3. What does a monthly average hide?

SELECT date, brent_usd, wti_usd, ROUND(spread_retail_vs_crude, 2) AS retail_minus_crude
FROM energy_market
WHERE date BETWEEN '2020-03-01' AND '2020-05-01'
ORDER BY date;

Kwiecień 2020: Brent 18,38 USD, WTI 16,55. Na danych dziennych WTI spada do −36,98 — średnia miesięczna znacznie wygładza dzienne spadki. Dlatego na stronie jest przełącznik dzienny/miesięczny.

April 2020: Brent $18.38, WTI $16.55. On daily data WTI hits −36.98 — the monthly average smooths the daily drops. That is why the page has a daily/monthly switch.
