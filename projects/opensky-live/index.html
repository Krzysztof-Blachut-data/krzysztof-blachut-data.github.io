Dane publiczne z OpenSky Network API (wektory stanu ADS-B). Gdy przeglądarka nie może wywołać API, na przykład przez CORS na GitHub Pages, strona pokazuje zapisany snapshot z datą pobrania. Public data from the OpenSky Network API (ADS-B state vectors). When the browser cannot call the API, for example because of CORS on GitHub Pages, the page shows a saved snapshot with the fetch date.

Wynik: mapa, KPI i rozkład krajów z wektorów stanu, nie z wklejonego CSV. Źródło (live vs snapshot) i data ostatniej obserwacji są zawsze widoczne. Result: map, KPIs and country mix from state vectors, not a pasted CSV. Source (live vs snapshot) and last observation time are always visible.

Ruch lotniczy nad Polską (OpenSky ADS-B) Air traffic over Poland (OpenSky ADS-B)

Cel: pokazać, ile samolotów leci nad Polską w danej chwili, skąd pochodzą i jak wygląda ruch w przestrzeni. Źródło: żywe API OpenSky; gdy CORS albo sieć nie pozwoli, dashboard przełącza się na snapshot i pokazuje datę pobrania.

Purpose: show how many aircraft are flying over Poland right now, where they come from and how traffic is distributed. Source: live OpenSky API; if CORS or the network blocks it, the dashboard falls back to a snapshot and shows the fetch date.
